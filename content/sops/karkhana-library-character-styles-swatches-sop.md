## 1. Purpose of This SOP

This SOP explains how to create, organize, and use an **InDesign Library File** for standard book and lesson design. It also explains how to use **Character Styles** and **Swatches** to maintain consistency in fonts, colors, and repeated design elements.

This SOP is useful for designers who need to create multiple pages or lessons using the same:

* Visual system
* Layout style
* Icons
* Text boxes
* Colors
* Design elements

---

# 2. What Is an InDesign Library File?

An **InDesign Library File** is a file where frequently used design elements can be stored and organized. These elements can be reused again and again in different pages or InDesign documents.

A Library File helps designers **save time and maintain consistency**.

### Common Items That Can Be Stored in an InDesign Library

* Standard headers
* Activity boxes
* Question boxes
* Icons
* Labels
* Speech bubbles
* Step number designs
* Material section designs
* QR code boxes
* Image frames
* Instruction boxes
* Repeated page elements
* Complete layout sections

Instead of recreating the same design again and again, designers can simply drag the saved item from the Library into the page.

---

# 3. Why Should We Use an InDesign Library File?

Using a Library File helps to:

* Maintain the same design style across all lessons
* Save time while designing multiple pages
* Reduce mistakes in layout, spacing, font, and color
* Make the design process easier for new designers
* Keep all standard elements in one place
* Make collaboration smoother between team members

---

# 4. How to Create an InDesign Library File

## Step 1: Open Adobe InDesign

Open Adobe InDesign and open the project file where you want to create or use standard design elements.

## Step 2: Create a New Library

Go to:

**File → New → Library**

A new Library File will be created.

![Create a New Library](images/create-library.png)

## Step 3: Save the Library File

Save the Library File in the correct folder.

### Recommended File Name

**Project_Name_Library.indl**

### Example

**Karkhana_Lesson_Library.indl**

The Library File extension is:

**.indl**

## Step 4: Open the Library File

Open the Library File that you have just created.

After opening the Library File, the Library panel will appear in the workspace.

![Open the Library File](images/open-library.png)

---

# 5. How to Add Items to the Library

## Step 1: Create the Design Element

Create the design element that you want to make standard.

For example:

* Question box
* Title style
* Step design
* Material section
* Speech bubble
* Footer element
* Complete activity layout

Make sure the design is final before adding it to the Library.

### Check Before Adding

* Size
* Color
* Font
* Alignment
* Spacing
* Stroke
* Icon placement
* Overall consistency

![Create a Standard Design Element](images/create-standard-element.png)

## Step 2: Select the Object

Select the object or group of objects that you want to save.

If the design element has multiple parts, group them first.

Go to:

**Object → Group**

Or use the shortcut:

**Ctrl + G**

## Step 3: Drag the Object into the Library

Click and drag the selected object into the Library panel.

The item will now be saved inside the Library.

![Add Object to Library](images/add-to-library.png)

## Step 4: Rename the Library Item

Give the item a clear and understandable name.

### Example Names

* Standard Question Box
* Material Section
* Step Number
* Speech Bubble
* Activity Header
* QR Code Box
* Highlight Text Box
* Page Footer

Clear naming helps other designers easily understand and use the items.

---

# 6. How to Use Items from the Library

## Step 1: Open the Required InDesign Document

Open the lesson or book file where you want to use the Library items.

## Step 2: Open the Library File

Open the required **.indl** Library File.

## Step 3: Drag the Item into the Page

From the Library panel, drag the required design item into the page.

![Drag Library Item into Page](images/drag-library-item.png)

## Step 4: Adjust the Position

Place the item properly according to the page layout.

Make sure to check:

* Alignment
* Margins
* Spacing
* Page grid
* Text fitting
* Image fitting

## Step 5: Edit Only the Required Content

After placing the Library item, only change the content that needs to be changed.

For example:

* Replace the question text
* Replace the image
* Change the step number
* Update the material name

> **Important:** Do not change the standard design style unless required.

---

# 7. Best Practices for Creating a Good Library File

A good Library File should be **clean, organized, and easy to use**.

### While Creating a Library File

* Add only finalized design elements
* Use clear names for every item
* Group objects before adding them
* Avoid adding unnecessary or unfinished designs
* Keep standard spacing and alignment
* Use correct fonts and colors
* Use Character Styles for text
* Use Swatches for colors
* Keep similar items together
* Review the Library File before sharing it with others

### A Good Library File Should Include

* All repeated design elements
* Standard text boxes
* Standard icons
* Standard color elements
* Standard page sections
* Common layout blocks
* Correctly styled elements

# Character Styles in InDesign

## 8. What Is a Character Style?

A **Character Style** is a saved text style in InDesign. It stores text formatting such as font, size, color, and other character-level settings.

Character Styles help maintain the same text appearance throughout the document.

For example, instead of manually setting the font size and color every time, designers can create a Character Style and apply it whenever needed.

![Character Styles](images/character-styles.png)

---

# 9. Why Should We Use Character Styles?

Character Styles help to:

* Keep font styles consistent
* Save time while formatting text
* Avoid manual formatting mistakes
* Update text styles quickly across the document
* Keep the document professional and organized

---

# 10. What Can Be Included in a Character Style?

A Character Style can include:

* Font family
* Font style
* Font size
* Font color
* Tracking
* Leading
* Baseline shift
* Underline
* Capitalization
* Other character formatting options

---

# 11. How to Create a Character Style

## Step 1: Select the Text

Create or select the text that you want to style.

## Step 2: Finalize the Text Formatting

Set the correct:

* Font
* Font size
* Font color
* Font style
* Spacing
* Other formatting

Make sure the text looks final before creating the style.

![Finalize Text Formatting](images/character-style-formatting.png)

## Step 3: Open the Character Styles Panel

Go to:

**Window → Styles → Character Styles**

The Character Styles panel will appear.

## Step 4: Create a New Character Style

Click the **+ icon** at the bottom of the Character Styles panel.

A new Character Style will be created.

![Create Character Style](images/create-character-style.png)

## Step 5: Rename the Style

Double-click the new style and give it a clear name.

### Example Names

* Standard Text
* Standard Question
* Material Text
* Speech Bubble Text
* Highlight Text
* Step Number
* Sub-highlight Text

## Step 6: Save the Style

After naming the style, click **OK**.

The Character Style is now ready to use.

---

# 12. How to Use a Character Style

## Step 1: Select the Text

Select the text where you want to apply the style.

## Step 2: Apply the Character Style

Go to the Character Styles panel and click the required style.

The selected text will automatically change according to the saved style.

---

# 13. How to Update a Character Style

If you need to change a style:

## Step 1: Right-Click the Character Style

Right-click the style name in the Character Styles panel.

## Step 2: Choose Style Options

Click:

**Style Options**

## Step 3: Edit the Formatting

Change the font, size, color, or other settings as required.

## Step 4: Click OK

The Character Style will be updated.

If the style is used in different places, the updated formatting will apply wherever that style is used.

![Update Character Style](images/update-character-style.png)

# Swatches in InDesign

## 14. What Are Swatches?

**Swatches** are saved colors in InDesign. They help designers use the same colors consistently throughout the document.

Instead of picking colors manually every time, designers can save standard colors as Swatches and apply them whenever needed.

---

# 15. Why Should We Use Swatches?

Swatches help to:

* Maintain standard brand colors
* Keep colors consistent across pages
* Avoid using random color variations
* Make color editing faster
* Keep the design clean and professional

---

# 16. What Can Be Added as a Swatch?

We can create Swatches for:

* Fill colors
* Stroke colors
* Text colors
* Brand colors
* Section colors
* Highlight colors
* Background colors

---

# 17. How to Create a New Swatch

## Step 1: Open the Swatches Panel

Go to:

**Window → Color → Swatches**

The Swatches panel will appear.

## Step 2: Select or Create a Color

Choose the color you want to save.

You can create a color using:

* CMYK values
* RGB values
* HEX code
* An existing object color

![Select Color](images/select-swatch-color.png)

## Step 3: Click the Plus Icon

Click the **+ icon** at the bottom of the Swatches panel.

A new Swatch will be created.

![Create New Swatch](images/create-swatch.png)

## Step 4: Rename the Swatch

Double-click the new Swatch and give it a clear name.

### Example Names

* Primary Blue
* Secondary Orange
* Activity Yellow
* Highlight Green
* Text Black
* Light Background

## Step 5: Choose the Color Type

For print design, use:

**Process Color**

For professional print files, CMYK is usually preferred.

## Step 6: Click OK

The color is now saved as a Swatch.

---

# 18. How to Use a Swatch

## Step 1: Select the Object or Text

Select the shape, text, line, or frame where you want to apply the color.

## Step 2: Choose Fill or Stroke

Decide whether you want to apply the color to:

* Fill
* Stroke
* Text

## Step 3: Apply the Swatch

Click the required color from the Swatches panel.

The selected object or text will now use the saved color.

---

# 19. How to Update a Swatch

If a standard color needs to be changed:

## Step 1: Double-Click the Swatch

Open the Swatches panel and double-click the color you want to edit.

## Step 2: Change the Color Values

Update the required color values.

## Step 3: Click OK

The Swatch will be updated.

If the Swatch is used in multiple places, those places will update automatically.

![Update Swatch](images/update-swatch.png)

# Quality Checklist Before Sharing the Library File

Before sharing the Library File with other designers, check the following:

* [ ] All items are final and clean
* [ ] Items are properly named
* [ ] Objects are grouped correctly
* [ ] Fonts are correct
* [ ] Character Styles are applied
* [ ] Swatches are used correctly
* [ ] Colors match the standard design system
* [ ] No unnecessary objects are included
* [ ] Items are aligned properly
* [ ] Repeated sections are easy to edit
* [ ] Library File is saved in the correct folder
