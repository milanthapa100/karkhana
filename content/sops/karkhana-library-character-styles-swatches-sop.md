# Karkhana Library File, Character Styles & Swatches Design SOP

> This SOP explains how to create, organize, and use **InDesign Library Files, Character Styles, and Swatches** to maintain consistency across Karkhana lessons and book designs.

---

## 1. Purpose of This SOP

This SOP explains how to:

- Create and use an **InDesign Library File**
- Store and organize frequently used design elements
- Create and use **Character Styles**
- Create and use **Swatches**
- Maintain consistency in fonts, colors, layouts, and repeated design elements
- Build lessons efficiently using standardized design components

This SOP is useful for designers who need to create multiple pages or lessons using the same:

- Visual system
- Layout style
- Icons
- Text boxes
- Colors
- Design elements
- Lesson components

---

# 2. InDesign Library File

## 2.1 What is an InDesign Library File?

An **InDesign Library File** is a file where frequently used design elements can be stored and organized.

These elements can be reused again and again across different pages and InDesign documents.

Instead of recreating the same design repeatedly, designers can save the finalized element in the Library and drag it into a page whenever it is needed.

### Common Items That Can Be Stored in an InDesign Library

- Standard headers
- Activity boxes
- Question boxes
- Icons
- Labels
- Speech bubbles
- Step number designs
- Material section designs
- QR code boxes
- Image frames
- Instruction boxes
- Repeated page elements
- Complete layout sections

---

# 3. Why Should We Use an InDesign Library File?

Using a Library File helps to:

- Maintain the same design style across all lessons
- Save time while designing multiple pages
- Reduce mistakes in layout, spacing, font, and color
- Make the design process easier for new designers
- Keep standard design elements in one place
- Make collaboration smoother between team members
