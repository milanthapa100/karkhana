## Description

The Karkhana site is now deployed and live. Content lives in `content/` on
GitHub and is validated automatically on every Pull Request before merging to
`main`. Once merged, the site rebuilds and the update appears automatically.

## Progress

- Validation pipeline running in CI on all content Pull Requests.
- Website deployed and rendering updates from `content/updates/`.
- First real content merged and published to the live site.

## Next Steps

- Add more content types (projects, people, events, resources).
- Enforce the Validate check in branch protection.
- Onboard additional contributors to the standard workflow.
